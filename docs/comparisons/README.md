## Capture methods

There are 48 unaltered viewport screenshots, grouped into 24 before/current pairs, plus the exact original and current icon PNGs for Checkers and Connect Four. Every screenshot has a matching viewport, explicit theme, production build mode, and game state hash across revisions. No screenshot reported a browser runtime error, failed HTTP request, or document-level horizontal overflow.

Sources were exported from Git into isolated ordinary directories outside the repositories. Both revisions of each app used that repository's currently installed dependency tree and the same Expo production export command. This compares source and assets with a shared toolchain; it is not a reconstruction of the historical dependency environment. Repository checkouts were not changed.

Phone screenshots use 390 × 844 CSS pixels; desktop uses 1440 × 900; compact chess uses 320 × 568. All captures use device scale factor 1, en-US locale, UTC timezone, matching light/dark browser preferences, and no browser chrome. Screenshots show the visible viewport; content below it is not added artificially. Raw files under screenshots/ are unedited. Composites add labels outside the screenshot frames and desktop overviews uniformly scale the originals for readability.

Chess starts through the real UI with identical mirror armies, full army size, two kings, local play, and seed 1. A deterministic Math.random seed is installed in each fresh browser context; sounds and haptics are off and onboarding is marked seen. Cosmetic board shots have the same local cosmetic entitlement on both revisions. The cosmetic preview comparison starts with no entitlement and opens the locked Neon option without making a purchase.

Sudoku uses a valid state generated by the real engine with seed 20261011, three pencil notes in the same selected cell, and the same puzzle on both revisions. Motion is reduced and the browser clock is paused, then advanced by 1200ms to hold the timer at the same point. The Classic, Sunset and Paper packs are named in each comparison.

Checkers makes four legal moves through the UI: b3-a4, g6-h5, d3-c4, e6-f5. Connect Four drops into columns 1, 7, 2, 7. Both show turn 4 and all five history states with Classic boards and pieces. Onboarding is marked seen and sound/haptics are off.

The compact chess scroll comparison applies the same wheel scroll to both versions. The current Resign button is fully visible after scrolling; the original button remains below the viewport. The original Checkers/Connect Four production desktop screens rendered successfully, so these images do not portray their separate development-only assertion as a production failure.

These are browser captures with phone viewport emulation. They do not establish native device rendering, safe-area insets, or launcher icon masks. The icon comparison uses the configured assets/icon.png files; current icons were rendered with Blender during the earlier UI work. No new 3D asset was required for this capture task.
